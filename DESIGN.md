# Retail Pulse — direction visuelle

Une interface de collecte terrain avec une composition éditoriale inspirée de la référence Monad et une palette JTI. Le formulaire reste prioritaire sur les effets visuels.

- Palette : vert JTI `#00BB31`, texte noir `#101111`, vert de texte `#087A29`, fond `#F6F5F0`, surfaces `#FDFDFB`, séparateurs `#E2E3DB`.
- Titres : Instrument Serif regular / italic, 40–76 px. Interface : DM Sans. Arabe : Noto Sans Arabic, sans espacement des lettres, interligne ≥1,5, direction RTL au document.
- Composition : navigation latérale fixe 248 px ; largeur maximum 1450 px ; contenu 48 px de retrait ; grille de formulaire avec résumé de progression sur ordinateur ; navigation mobile repliée.
- Surfaces : rayon 8–14 px pour les contrôles et feuilles ; boutons principaux 48 px minimum avec rayon pilule ; contours fins, ombres limitées.
- Mouvement : entrée du bloc d’accueil via Tailark, tabs via Smooth UI, fond Paper MeshGradient ; respect du mouvement réduit et fond CSS si WebGL2 absent.
- Le vert signale la sélection et l’action. Disponibilité et progression ont aussi des libellés / valeurs textuelles.
- Les photos attendent les fichiers utilisateur ; aucune image de pack reconstituée.
